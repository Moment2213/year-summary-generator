# 年终总结生成器 (Year Summary Generator)

填 5 个空，10 秒生成一版能交差的年终总结。支持 4 种风格（端正汇报体 / 述职答辩体 / 简洁邮件体 / 轻松朋友圈体），可一键复制全文、下载 Markdown。

## 在线使用

- 国内直连（腾讯云 COS 静态网站）：https://year-summary-generator-1436233077.cos-website.ap-guangzhou.myqcloud.com/
- 主站（GitHub Pages）：https://moment2213.github.io/year-summary-generator/

单文件网页：双击 `index.html` 也能离线使用。所有内容仅在浏览器本地处理，不上传任何数据。
